# 17 – Nowe formaty eksportu i import

Zgłoszenie użytkownika (2026-10-30): dodać formaty eksportu oraz importy. Szczegóły do ustalenia przy implementacji.

Dziś eksport to `.md` z frontmatterem dla rozdziału (D10) i `.zip` dla folderu (D18). Importu nie ma.

## Zakres

- Nowe formaty eksportu.
- Import opowiadań.
- Do ustalenia przy starcie (pytanie do użytkownika):
  - jakie formaty eksportu i czy dotyczą rozdziału, folderu, czy obu;
  - jakie formaty importu i czy import dotyczy pojedynczego rozdziału, czy całego folderu (np. `.zip` z eksportu);
  - gdzie trafia import i co przy zajętym tytule;
  - co z notatkami i komentarzami przy eksporcie i imporcie;
  - limity rozmiaru pliku;
  - nowe pakiety (instalacja tylko po zgodzie użytkownika).
- Wpis w `decisions.md`.

## Kryteria akceptacji

Do uzupełnienia po ustaleniu zakresu.

## Testy

Do uzupełnienia po ustaleniu zakresu. Import musi mieć testy izolacji użytkowników (D1).
